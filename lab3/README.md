# **Теоритичні питання**

### Розклад сингулярних значень (SVD) і його застосування для підбору рекомендацій


1. Спершу беремо матрицю ( A ), де рядки представляють користувачів, а стовпці - елементи (або щось інше)


2. Виконання SVD: Виконується розклад матриці ( A ) на три матриці: ( A = U Sigma V^T ), де:
   - ( U ) - нормована матриця лівих сингулярних векторів (користувачів),
   - ( Sigma ) - діагональна матриця сингулярних значень,
   - ( V ) - нормована матриця правих сингулярних векторів (елементів).


3. Вибір рангу ( k ): вибирається кількість значущих сингулярних значень ( k ) для зменшення розмірності.


4. Оцінка користувачів і елементів у зменшеному просторі: враховуючи обраний ранг ( k ), зберігаються лише перші ( k ) сингулярних значень у матриці ( Sigma ), і відповідні стовпці у матрицях ( U ) і ( V ).


5. Реконструкція матриці: Реконструюється матриця оцінок, використовуючи зменшені матриці ( U_k Sigma_k V_k^T ). Це дозволяє отримати наближену матрицю оцінок.


### метод SVD можна використовувати в: 

1. Підборі рекомендацій.
2. Обробці зображень.
3. Обробці тексту і аналіу даних.
4. Обробці сигналів.
5. Біоінформатиці.
6. Економіці та фінансах.
7. Машинному навчанні.
8. Наукових дослідженнях.

Параметир k - впливає на точність. Чим більше k тим більше точність.

## Переваги
- Зменшує розмірнісь.
- Покращення якості даних.
- Застосованісь у різних сферах.

## Недоліки
- Обчислювальна складність.
- Чутливість до параметру k.
- Недоліки в реальних даних можуть спотворити результат наприклад наявність пропущених даних.
